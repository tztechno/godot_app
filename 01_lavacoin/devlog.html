01 / アセット

アセットゼロ、コードで全部

インポートした3Dモデルやテクスチャはひとつも無い。キャラクターはカプセルと球体を6個組み合わせただけ、 アリーナの壁もコインも溶岩も、すべて起動時に BoxMesh / CapsuleMesh / CylinderMesh をスクリプトから生成している。

走行アニメーションもボーンやAnimationPlayerを使わず、股関節・肩のNode3Dピボットをsin波で回転させているだけ。 「絵」を作らず「手順」を作る、という発想がこのゲームの一番のこだわり。

scripts/player.gd — 脚を1本組み立てる手順
func _make_limb(pivot_pos, radius, height, material):
    # 股関節・肩の位置にピボットを置く
    var pivot := Node3D.new()
    pivot.position = pivot_pos
    _body_root.add_child(pivot)

    # そこにカプセルメッシュをぶら下げる
    var capsule := CapsuleMesh.new()
    capsule.radius = radius
    capsule.height = height
    # ↑ この pivot.rotation.x を sin(time) で動かすと走る
    return pivot

02 / 起動

始まるまで、始まらない

最初のバージョンはシーンを開いた瞬間に3分のタイマーが動き出していた。ブラウザを最大化する前にラウンドが終わっている、 という本末転倒な問題が実プレイで発覚した。

直したのは「押されるまで何も起きない」状態機械を1つ挟んだこと。START ボタンの pressed シグナルが発火するまで、溶岩もコインも生成せず、プレイヤーの物理演算も止めたまま待機する。

scripts/game_manager.gd
func _process(delta):
    if not game_started or game_over:
        return  # タイマーも溶岩も、ここで完全に停止
    time_left -= delta

見つけ方: 実際にブラウザで動かして「あれ、始まってる」と気づいたことがきっかけ。 仕様書だけでは出てこない類のバグだった。

03 / 操作

操作とカメラの向き

移動は矢印キーをワールド座標にそのまま対応させる方式(Input.get_vector)。 素直な実装のはずが、「方向転換がやりにくい」という指摘を受けた。原因はカメラ側にあった。

当初はカメラがプレイヤーの向いている方角に合わせて自分も回転する仕様だった。キャラクターが向きを変えるたびに 画面全体が振り回され、キー入力と画面上の方向の対応がフレームごとに崩れる。

固定角度で位置だけを追従する方式に変更して解決した。ワールド空間で固定したオフセット (0, 13, 9) をプレイヤー座標に足すだけで、回転はさせない。 画面上の「上下左右」が常に一定になり、矢印キーとの対応が最後まで崩れなくなる。

04 / 脅威

追いかけてくる溶岩

溶岩の中身はAIと呼べるほどのものではなく、Area3D が毎フレーム プレイヤーへの方向ベクトルを取り、一定速度で近づくだけの単純な物理。当たり判定も body_entered シグナルと "player" グループの照合だけで済ませている。

最初は3体同時に追跡させていたが、同じロジックで同じ相手を追う3体は、時間が経つと1点に収束して重なって見えてしまう。 プレイテストの指摘で1体に整理し、代わりに「時間とともに速くなる」仕組みを足した。

05 / 経済

リスクと報酬の配置

アリーナは40×40。そのうちスタート地点のすぐ北、16m×9mほどの一角だけが「溶岩スペース」で、 ここに高額コイン(50)、残りの安全なスペースに低額コイン(10)を撒く。 危険なほど報酬が高い、という単純な配置だけで駆け引きが生まれる。

コインは取られると3秒後に同じカテゴリで再出現するので、3分間ずっと拾うものがある状態を保っている。

06 / 配信

配信パイプライン

公開先は GitHub Pages ——ただの静的ホスティングなので、Godotのweb書き出しが標準で使う SharedArrayBuffer 系のマルチスレッド機能は動かせない (Cross-Origin-Opener-Policy / Cross-Origin-Embedder-Policy ヘッダーをGitHub Pages側で設定できないため)。

このゲームはスレッドを一切使っていないので、書き出し設定で variant/thread_support を切って対応。出力された index.html 内の GODOT_THREADS_ENABLED が false になっていることを確認してから配信している。

エクスポート & デプロイ
# headlessでWeb向けにビルド(スレッド不使用)
godot --headless --export-release "Web" build/web/index.html

# 既にPagesが有効なリポジトリへそのままpush
git add 01_lavacoin
git commit -m "Add lava & coin arena game"
git push origin main

3分だけ、逃げて拾って。

ブラウザだけで動く。インストールも、待ち時間もほぼ無い。
